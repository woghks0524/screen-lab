    Unity 체험
    
      
    웹 모션보다 큰 움직임, 그러니까 물체가 떨어지고 부딪히는 물리, 걸어 다니는 3D 세계, VR·AR이 필요하면 게임 엔진을 써요. Unity는 그중 가장 널리 쓰이는 엔진이에요. 아래 게임은 진짜 Unity 6로 만들어 웹으로 내보낸 거예요.
    
    
    
    
    
      
    
        
        
      
    
      
    
        
    조작법
    
          
    • 방향키·WASD 공 굴리기 (휴대폰·태블릿은 가고 싶은 쪽 화면을 꾹 누르기)
    • 스페이스 점프 · 보라색 경사로로 날아 보세요
    • 목표 노란 별 8개 모으기, 주황 상자 탑 무너뜨리기
    • R 처음부터 다시
    
          
    키보드가 안 먹으면 게임 화면을 한 번 눌러 주세요.

    스크립트(C#)움직임 규칙. 키를 누르면 공에 힘을 주는 코드

    Unity 시작하기 (AI와 함께)
    
      
      
        
    1. Unity Hub를 설치하고 Unity 6 에디터를 받아요. 개인용 라이선스는 무료예요.
      2. 
        
    2. 새 프로젝트에서 템플릿(2D, 3D, VR)을 골라요.
      3. 
        
    3. 코드 편집기로 VS Code를 연결해요. Unity 코드는 C# 파일(.cs)이에요.
      4. 
        
    4. AI에게 부탁해요. 예: "플레이어가 방향키로 움직이고 스페이스로 점프하는 C# 스크립트 만들어 줘". Unity MCP를 연결하면 Claude Code 같은 AI가 에디터 안의 물체까지 직접 만들어 줘요.
      5. 
        
    5. File → Build Profiles에서 Web을 골라 빌드하면, 링크 하나로 학생들에게 나눠 줄 수 있어요.
      6. 
      
    
      
    웹앱과 다른 점: Unity는 물체를 화면에 끌어다 놓고 스크립트를 붙이는 손 작업이 많아요. 그래서 코드만 쓰는 웹앱보다 AI 혼자 끝내기 어려워요. 처음에는 AI가 만든 스크립트를 물체에 붙이는 일부터 직접 해 보세요.

    여섯 가지, 하나씩 자세히
    
    
    HTML
    화면에 무엇이 있는지
    
      
    • 태그로 내용을 감싸 "이건 제목, 이건 버튼"이라고 이름표를 붙여요. <h1> 큰 제목, <p> 문단, <input> 입력칸.
      • 
      
    • 꾸밈이 없어도 브라우저가 기본 모양으로 보여 줘요. 버튼은 생기지만 눌러도 아무 일이 없어요.
    
      
    <button>정답 확인</button>   ← "여기에 버튼이 있다"까지만
    
    
    CSS
    어떻게 보이는지
    
      
    • 선택자로 대상을 고르고 속성: 값으로 모양을 정해요. 색, 크기, 여백, 둥근 모서리, 배치.
      • 
      
    • HTML은 그대로 두고 CSS만 바꿔도 분위기가 완전히 달라져요. 휴대폰·PC 배치를 바꾸는 반응형도 CSS예요.
    
      
    button { background: #2a6fdb; color: white; border-radius: 10px; }
    
    
    JavaScript
    어떻게 움직이는지
    
      
    • "버튼을 누르면 답을 읽어 정답과 비교하고 결과를 바꿔 쓴다" 같은 순서를 적어요.
      • 
      
    • 점수, 다음 문제, 타이머처럼 변하는 것은 전부 JavaScript. 브라우저가 기본으로 알아듣는 유일한 프로그래밍 언어예요.
    
      
    button.onclick = () => { if (answer === "서울") score++; };
    
    
    TypeScript
    JavaScript + 종류 검사
    
      
    • 값마다 종류(타입)를 적어요. score: number라고 써 두면 점수 칸에 글자를 넣는 실수를 저장하기 전에 빨간 줄로 알려 줘요.
      • 
      
    • 브라우저는 TypeScript를 바로 못 읽어서, 실행 전에 JavaScript로 바꾸는(빌드) 과정을 거쳐요. 4번 탭도 화면 안에서 바꾼 뒤 실행하고 있어요.
      • 
      
    • 파일 이름이 .ts, .tsx예요. Next.js·AI Studio가 만든 코드는 대부분 TypeScript예요.
    
      
    let score: number = 0;
score = "열";   // ✕ 오류: 숫자 칸에 글자를 넣을 수 없어요
    
    
    Tailwind CSS
    짧은 이름으로 꾸미기
    
      
    • <style>을 따로 쓰지 않고, 태그의 class에 미리 정해진 짧은 이름을 나란히 붙여 꾸며요.
      • 
      
    • bg-blue-600 파란 배경, p-3 안쪽 여백, rounded-xl 둥근 모서리, hover: 마우스를 올렸을 때.
      • 
      
    • AI가 만든 화면에 class="..."가 길게 붙어 있으면 거의 Tailwind예요.
    
      
    <button class="bg-blue-600 text-white p-3 rounded-xl hover:bg-blue-700">
    
    
    React
    조각으로 조립하는 화면
    
      
    • 화면을 컴포넌트(버튼, 카드, 점수판 같은 조각)로 나눠 함수로 만들고, 레고처럼 조립해요.
      • 
      
    • 상태(state)가 바뀌면 화면이 저절로 다시 그려져요. 3번 탭처럼 "점수 글자를 찾아서 바꿔라"를 일일이 쓰지 않아요.
      • 
      
    • JavaScript 안에 HTML 같은 태그를 섞어 쓰는 JSX 문법을 써요. 파일 이름은 .jsx, TypeScript와 섞으면 .tsx.
    
      
    const [score, setScore] = useState(0);
<ScoreBadge score={score} />   ← 직접 만든 조각을 태그처럼
    

    
    
      AI에게 부탁할 때 이렇게 나눠 말하면 정확해져요
      HTML: "문제 아래에 입력칸과 버튼을 하나씩 넣어 줘"
      CSS / Tailwind: "버튼을 파란색으로, 글씨를 더 크게, 카드 모서리는 둥글게 해 줘"
      JavaScript / React: "버튼을 누르면 정답인지 확인하고 점수를 1점 올려 줘"
